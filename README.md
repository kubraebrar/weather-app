# Weather App 🌤️

This is a simple web application that allows users to check the **current weather** for any city.  
It uses the OpenWeatherMap API to display temperature, weather description, and icons.

---

## 📌 Features
- Users can search for a city to get its weather information.  
- Displays weather icon and description.  
- Temperature is converted from Kelvin to Celsius.  
- Shows a warning message if an invalid city name is entered.  

---

## 📌 Technologies
- HTML  
- CSS  
- JavaScript (vanilla JS)  
- [OpenWeatherMap API](https://openweathermap.org/api)
